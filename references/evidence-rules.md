# 证据与数据边界

## 制图前的数据检查

对每张图保留足以复现的数据与来源。按图的需要记录：研究/来源标识、人群、干预与对照、指标定义、分母或分析集、时间点、单位、估计值与区间、来源位置、事实/假设/待核状态。不要求无关字段，也不为凑齐字段编造数据。

- 用户材料中的数字可用于整理，但“用户提供”不等于“已独立核验”。图注与结论保持相应证据状态。
- PDF、Word、图片里的数字按当前文件分析流程提取；图形、复杂表格与 OCR 疑点核对原件。
- 图片自动 alt 文本、OCR 摘要、表格转 Markdown 结果只能辅助定位，不能替代看原图。行标签、图例和数字可能被错配。
- 涉及新的医疗/监管结论或当前政策时按任务需要查证原始来源；纯排版任务不擅自扩展为全报告医学审计。

## 避免图表产生额外结论

| 情形 | 处理 |
|---|---|
| 不同研究的终点、评估周数、人群或对照不一致 | 保留差异，描述性展示不推出疗效优劣；差异过大则分面或使用表格 |
| 某研究没有对照组数据 | 留空/标“未报告”，不能填 0；不要把另一研究的对照借来连接 |
| 多组范围 / 测量范围 / 置信区间 | 名称、线型和图例分清，不用“区间”含混带过 |
| 不同来源数字冲突 | 查明版本和口径；不能平均、挑选更好看的值或隐去冲突 |
| 计划、情景估算、目标阈值 | 与观测数据区分，标注假设或“拟定/待确认” |
| 小样本 / 非随机探索性信号 | 图题与结论不升级为确定性获益或监管认可 |
| 风险可能性未知 | 放未知区，不当低风险；主观等级不映射为虚构概率 |
| 关键条件没有确定 | 用“待确认”的条件或缺口表，不填造 Go/No-Go 阈值 |

坐标轴应支持真实解释：条形长度比较通常从零开始；点图或森林图可以用合适区间，但范围、刻度与效应方向要明确。不要截断关键数值、用双轴或面积夸大差异。

来源引用应能追到数据所在表/页/记录；技术上画成功不意味着医学审核通过。无需向用户重复泛化免责声明，但不能把版式验收写成内容获批。

## 内部资料

优先本地生成数值图和自包含 SVG，不将私有材料发往外部绘图服务。要使用需上传资料的工具时，按当前授权范围判断；技能本身不构成上传许可。向用户指定的飞书文档插入已授权图表，复用现有合法认证，不输出凭据。
