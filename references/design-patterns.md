# 设计模式：临床研发图文报告

## 风格依据与边界

本技能据用户于 2026-11-08 指定的飞书报告风格定制。已直接观察分组疗效点图、阶段关口图和风险矩阵；文档结构还包含 MIC 对比、样本量比较、研究设计、开发路线和甘特图。

抽取的是以下视觉方法，不保存示例中的内部项目数据、药物判断或研发时间表，也不复制整篇报告。无需每次写作都重新访问示例；用户另给风格时按新要求调整。

| 已观察到的方法 | 可复用的设计决策 |
|---|---|
| 疗效图按类别分组，药物组蓝点、对照灰点，点旁直接标数 | 按有意义的类别分组，减少读者在图例与图形间来回寻找 |
| 行标签含剂量、疗程、研究阶段、评价时间，图底注明口径差异 | 将影响解释的字段留在图或紧邻图注，不为简洁抹掉可比性限制 |
| 关口图用蓝色阶段带、橙色菱形和向下箭头连接条件 | 将“什么时候判断”与“凭什么判断”分层呈现 |
| 风险矩阵用浅色格子和编号标签，未知单列为灰色区域 | 颜色辅助阅读，文字说明含义；未知不混入低风险 |

示例导出的个别画板有较大空白画布，不照搬空白比例：围绕有效内容设置边界，让正文中的预览容易阅读。

## 配色与排版

以下为近似示例风格的建议色值，不是对原图的精确采色结果：

| 用途 | 色值 / 方法 |
|---|---|
| 主要数据、研究路径 | `#2878D8` 蓝；阶段带 `#EAF3FC` |
| 参照数据、背景连接 | `#A7A6A0` 灰；细网格 `#E3E2DD` |
| 决策关口、待确认 | `#EA6B36` 橙；浅底 `#FFF0E6` |
| 正文与次级文字 | `#20252B` / `#5E6570` |
| 风险背景 | 浅绿 `#E3F1E5`、浅黄 `#FFF3D2`、浅橙 `#FBE5D8`、浅红 `#F7DDDF` |
| 未知、未分级 | 中性灰底 `#F1F2F3`，明确写“未知/待确认” |

- 同一篇文档颜色语义稳定；不要让同一蓝色在相邻图里分别代表试验组和对照组。
- 不只用红绿区分状态；同时提供文字、符号或线型。
- 标题、主体、注释形成三级层次；不要用大量渐变、阴影、图标抢占数据空间。
- 数据图优先直接标数；图例说明点、线、区间分别代表什么。
- 以最终显示宽度反推字号。先按约 800–1000 px 阅读宽度试看，实际以文档为准；PNG 可以导出约两倍像素，但必须检查缩小后的文字。
- 画板字号可参考本次样本量决策图的实际效果：主标题 22、重点数字 24、卡片标题和结论 18、正文 16、说明或脚注 15。这里是该画板坐标体系下的起点，不是所有画板通用的绝对字号；画布尺寸、缩放和文档预览宽度改变时应重新调整。
- 重点数字略大于标题即可，不要让数字挤占卡片空间；标题、正文和注释保持清晰层级。优先通过精简文字、调整卡片尺寸与间距改善布局，保留连接关系和必要说明。
- 写入后在飞书文档的实际页面宽度下检查整张画板，再放大查看小字；确认没有重叠、截断或过度留白。更新既有画板时，核对内容、数字和连接关系仍与原图一致。
- 标签太长时，拆行、拆组或拆图；不以缩小字号解决所有问题。桌面横向画板在窄屏上不可读时，优先竖向分层。
- 布局方向按内容关系和页面效果选择：顺序流程、并行阶段或对比卡片导致画板过长时，尝试横向排列、分行或分成关联的多张图；保留阅读顺序和依赖关系。横向版仍须在飞书实际宽度下检查，若缩放后文字太小或需要频繁横向滚动，则改为分行、拆图或竖向布局，不强制横向。

## 选择图形：按问题，不按装饰偏好

### 临床结果 / 参数对比

- 多个数值量级：横向点图，左侧保留研究/人群/时间点信息。
- 同一研究内试验与对照：可以用连接点图；线只连接该研究对应的两组，不跨研究连线。
- 同类多个剂量组的最小值到最大值：标签明确写“组间范围”，不能画成“95% CI”。
- 效应量及其置信区间：使用真正的森林图，明确效应尺度和无效线；不能用组别治愈率伪装为效应量。
- 不同研究不可直接比较：可按研究分面，或在描述性量级图中显著标出差异；若展示仍会误导，就改证据表。默认不要按疗效数值降序制造药物排名。
- 模板 `comparison-template.py` 只提供点值比较的视觉起点；对数轴、删失值、区间和森林图需另行正确实现。

### MIC / PK 与检出限

- 跨数量级时考虑对数轴，写明单位；对数轴不得放零。
- 不同菌株、实验机构、方法或批次分组；不要连成时间趋势。
- `<` / `>`、低于定量下限等用明确符号、箭头或注释呈现；不要替换成精确数值或零。

### 样本量 / 情景估计

- 情景作行，不同把握度用点形或并列系列；疗效估计与安全性规模分层标识。
- 图注包括主要假设、随机比例、α、把握度、失访处理及计算方法。
- 不将估计值写成已确定方案，也不把安全性样本规模画成疗效计算推导结果。

### 研发时间线与跨职能泳道

- 时间线适合阶段先后；甘特图适合时长与重叠；泳道适合临床、非临床、CMC、注册之间的依赖。
- 日期未确定时使用相对月份或“待确认”，不编造年月日以便绘图。
- 明确关键依赖和里程碑，避免把所有工作首尾串联；不能把规划周期说成承诺日期。
- 图过大时分“总路径”和“近期细化”，用编号关联。

### 研究设计与 Go/No-Go

- 研究设计：人群 → 分组/队列 → 给药 → 随访 → 终点评估；同一时间尺度对齐不同组。
- 关口：上方阶段带，中间菱形节点，下方给出判断依据和未解决事项。
- 决策树：每个分支的条件可识别，包含不满足/数据不足的去向；不能只画 Go 而隐藏 No-Go。
- 条件、阈值、负责人尚未确定时明确标注；模板中的阶段数量没有约束力。
- 使用 `gate-map.svg` 时按内容调整节点与画布；避免把长段落塞进卡片。

### 风险与证据缺口

- 有分级依据：影响 × 可能性矩阵，风险编号与原生风险表对应；不能把主观分级暗示成统计概率。
- 未知可能性单列；未知影响也要单列或放到独立待评估区，不强行定位。
- 没有分级依据：证据缺口矩阵更合适，列为“已知、缺失证据、影响哪个决策、补充路径”。
- 颜色表达优先级，不替代依据；长缓解措施留在原生表格，画板只保留识别标签。

## 文档中的位置

图题和图号依文档既有编号；图紧随首次解释它的段落。关键口径与限制可在图中保留短注，同时在可搜索的原生正文中给出完整来源链接。画板内短标签与正文详述互补，不把整章文字转成一张图片。

背景和论证仍用有承接的段落；数据查阅用原生表格；分支、依赖和差异交给图示。不要把所有内容套成彩色卡片。
